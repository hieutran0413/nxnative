# Product Roadmap

| Phase | User outcome | Feature IDs | Exit evidence | Status |
| --- | --- | --- | --- | --- |
| Runtime foundation | Host executes supported Switch software and translates platform services | Existing profiles and runtime documentation | Per-game launch/save/gameplay evidence | in progress |
| TOTK A16-class compatibility | Correct no-BC rendering and measurable memory/performance behavior | TOTK 60 fps feature packet | Gameplay, image parity, <=3072 MiB simulation; device evidence separate | gated |
| Broader title/device support | Each supported title and hardware tier meets its own gates | Per-game profile and evidence | Verified title matrix; no inferred aggregate pass | ongoing |
| Release | User can build and sideload the unsigned package from their own files | README and build scripts | Packaging and user device verification | per build |

Do not use dates without a real owner, dependency review, and delivery evidence.
