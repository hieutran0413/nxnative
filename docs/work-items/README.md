# Feature Work Items

The active TOTK packet predates this scaffold and remains owned at `docs/engineering/totk-a16-60fps.md`. Do not move or duplicate it. Use this folder only for future work items when repository conventions adopt this location.

Create:

```text
active/<FEATURE-ID>-<short-name>/FEATURE_PACKET.md
```

Copy `docs/templates/FEATURE_PACKET.md`.

Allowed status:

```text
draft
design-ready
code-ready
in-progress
verification
accepted
blocked
cancelled
```

A `code-ready` packet records readiness; implementation still follows the user-authorized scope. Explicitly scoped maintenance does not require a new packet. Archive after verified acceptance.
